🧑‍🏫 Dashboard Guru

Soal otomatis dibuat dari kalimat-kalimat pada materi di atas dan ditambahkan ke Bank Soal level yang sedang dipilih. Guru tetap dapat mengedit setiap soal pada tab Bank Soal.

🌐 Publikasikan ke GitHub (agar terlihat di semua HP)

Materi, Bank Soal, dan Pengaturan yang kamu ubah hanya tersimpan di perangkat/browser ini. Agar semua HP siswa melihat versi terbaru saat membuka link GitHub, lakukan langkah berikut setiap selesai mengedit:

  1. Klik tombol "⬇️ Unduh data.json" di bawah ini.
  2. Buka repository GitHub kamu, cari file data.json di folder yang sama dengan index.html.
  3. Ganti (replace/upload) file data.json lama dengan file hasil unduhan tadi, lalu Commit.
  4. Tunggu 1–2 menit, lalu minta siswa membuka ulang link-nya (refresh) — soal terbaru akan otomatis termuat.

"Muat Ulang dari data.json" berguna jika kamu ingin membuang draf lokal di HP ini dan memakai versi yang sudah dipublikasikan di GitHub.

🗺️ Cara Bermain

Jelajahi 10 wilayah/level secara berurutan. Setiap level berisi beberapa soal dengan bentuk yang berbeda-beda (pilihan ganda, isian, mencocokkan, dsb). Jawab soal dengan benar untuk mendapatkan 🔑 Kunci Pengetahuan dan membuka level berikutnya. Tidak ada sistem nyawa — setiap jawaban salah akan mengurangi ⭐ Poin, jadi jawablah dengan cermat!
